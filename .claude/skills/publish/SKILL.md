# 記事公開

Zenn記事を公開する。基本は予約公開を推奨。

## 使い方

```
/publish                    # 予約公開（推奨日時を提案）
/publish --now              # 即時公開
/publish --at "2026-01-22 07:00"  # 日時指定
```

## 手順

### 1. 対象記事の確認

引数で指定がなければ、`articles/` 配下の下書き記事を一覧表示して選択。

### 2. 自動チェックの実行

以下を順番に実行:

1. **`/check-controversy`** - 炎上チェック（🔴高リスクは公開ブロック）
2. **`/review-article`** - 記事レビュー
3. **`/proofread`** - 校正チェック

### 3. 公開日時の決定

#### `--now` の場合

即時公開に進む。

#### `--at` の場合

指定日時を使用。

#### オプションなしの場合

推奨日時を計算:

| 今日 | 次の公開日       |
| ---- | ---------------- |
| 月曜 | 翌日（火）07:00  |
| 火曜 | 翌日（水）07:00  |
| 水曜 | 翌日（木）07:00  |
| 木曜 | 翌日（金）07:00  |
| 金曜 | 3日後（月）12:00 |
| 土曜 | 2日後（月）12:00 |
| 日曜 | 翌日（月）12:00  |

**土日は公開を避ける**（閲覧数が少ない）

祝日・既存予約との重複もチェック。

### 4. 日時確認（予約公開の場合）

**`published_at` は一度設定すると変更不可。**

必ずユーザーに確認:

```
📅 2026年1月22日（水）07:00 で予約します。
この日時で間違いありませんか？ (yes/no)
```

明示的な「yes」を得てから設定。

### 5. 公開処理

**即時公開:**

```yaml
published: true
```

**予約公開:**

```yaml
published: true
published_at: "2026-01-22 07:00"
```

コミット＆プッシュ:

```bash
git add . && git commit -m "publish: 記事タイトル" && git push
```

### 6. 公開後の案内

```
✅ 予約公開を設定しました

- 📅 公開予定: 2026年1月22日（水）07:00 JST
- 🔗 公開後URL: https://zenn.dev/ユーザー名/articles/slug

⚠️ published_at の日時は変更できません。
```

## 間違えた場合のリカバリー

push後に日時を修正したい場合:

1. 記事を削除
2. 新しいslugで作成
3. 内容をコピーして正しい日時を設定
